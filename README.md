# Commercor Full-Stack E-Commerce Platform

Commercor is a collaborative full-stack e-commerce platform with separate customer and administration applications.

## Project Structure

- `customer-web` — Customer-facing web application
- `customer-api` — Backend API for customer operations
- `admin-web` — Administration dashboard
- `admin-api` — Backend API for administration operations

## Technologies

- React
- Next.js
- Vite
- TypeScript
- NestJS
- TypeORM
- PostgreSQL
- Tailwind CSS
- Ant Design
- Docker

## Features

- Product browsing and search
- Categories and product filters
- Customer registration and authentication
- Customer profiles and addresses
- Checkout and order management
- Administrative product and category management
- Customer and order administration
- Role-based access control
