## Commit message guidelines
We follow the Conventional Commits specification to keep a clean and readable Git history. Each commit message should follow the format:

`<type>`(optional-scope): `<short description>`

### Examples:
- feat(auth): implement Google OAuth login
- fix: resolve crash when loading dashboard
- docs(readme): add installation instructions
- refactor(core)!: drop support for legacy API

Allowed type values include:
`feat, fix, docs, style, refactor, test, build, ci, chore, perf, revert`
